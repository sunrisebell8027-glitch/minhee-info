개인정보처리방침

Codex Minhee는 사용자가 승인한 일정과 업무 자료를 아침 브리핑 작성·전달·보관에 이용합니다.

1. 접근하는 정보

Google Calendar에서 캘린더 목록과 선택한 개인·공유 캘린더의 일정을 조회합니다. 조회 응답에는 일정 제목, 시작·종료 시각, 설명, 장소, 상태, 식별자, 참석자 정보 등 일정에 입력된 정보가 포함될 수 있습니다. 브리핑 처리 과정에서는 일정 내용과 참석자 수 등 필요한 항목을 사용합니다.

Notion에서는 사용자가 연결한 학사일정, 공문, 프로젝트, 태스크와 브리핑 기록·메모를 읽습니다. 전달을 위해 Telegram 대화 식별자와 발송 결과를 처리합니다.

2. 이용 목적과 Google 권한

자료를 비교하여 마감, 준비할 일, 일정 충돌과 확인할 사항을 정리하고, 중복 발송을 방지하며, 사용자가 브리핑을 검토할 수 있도록 기록합니다.

현재 Google 연결은 calendar.events(일정 조회·수정)와 calendar.calendarlist.readonly(캘린더 목록 조회)를 요청합니다. 아침 브리핑에서는 조회만 수행합니다. 캘린더 일정 변경은 별도 승인이 필요한 작업입니다.

3. 인공지능 처리와 외부 전달

브리핑 작성을 위해 조회한 일정·업무 내용이 OpenAI의 Codex 처리 과정에 전달됩니다. 완성된 브리핑은 사용자가 승인한 Telegram 대화로 전송되며, 지정한 Notion 데이터베이스에 저장됩니다. 따라서 이 서비스의 모든 처리가 사용자 컴퓨터 안에서만 이루어지는 것은 아닙니다.

각 제공자의 데이터 처리·보관에는 해당 서비스 약관과 계정 설정이 적용됩니다. 제공자의 보관 기간이나 모델 학습 설정은 사용하는 계정의 설정과 정책을 확인해야 합니다.

Codex Minhee는 Google에서 받은 데이터를 광고, 판매 또는 신용평가 목적으로 이용하지 않습니다. Google 데이터의 이용과 전달에는 Google API Services User Data Policy와 제한적 사용 요건을 적용합니다.

4. 보관과 보호

Google 연결 인증 정보와 Telegram 봇 인증 정보는 macOS 키체인에 저장합니다. 인증 정보와 비밀번호를 공개 소개 페이지에 싣지 않습니다.

브리핑 초안과 실행 기록은 사용자 컴퓨터와 Codex 작업 기록에 남을 수 있습니다. 발송한 메시지는 Telegram에, 브리핑 보관본은 Notion에 남습니다. 현재 일정한 기간이 지나면 모든 기록을 자동 삭제하는 기능은 마련되어 있지 않으며, 사용자가 삭제하기 전까지 기록이 남을 수 있습니다.

공개 소개 페이지에는 실제 일정, 업무 자료, 브리핑 기록을 게시하지 않습니다. 소개 페이지 자체에는 로그인 입력란, 분석용 스크립트, 광고 또는 추적 쿠키를 추가하지 않습니다. 이 페이지는 GitHub Pages에 게시할 예정입니다. GitHub는 보안 목적으로 방문자의 IP 주소를 기록·보관합니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.

5. 연결 해제와 삭제

Google 계정의 외부 서비스 연결 관리에서 Codex Minhee의 접근 권한을 철회할 수 있습니다. 권한 철회 후에는 해당 인증 정보로 Google 자료를 새로 조회할 수 없습니다.

권한 철회만으로 이미 저장된 브리핑이나 예약된 자동화가 삭제되지는 않습니다. 사용자는 자동화 중단과 로컬 인증 정보·기록 삭제를 요청하고, Telegram 메시지와 Notion 보관본을 각 서비스에서 삭제할 수 있습니다. Codex 작업 기록도 해당 서비스의 삭제 기능으로 별도 관리합니다.
